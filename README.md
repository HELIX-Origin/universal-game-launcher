## ⚡ Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (v20+)
- [Rust](https://www.rust-lang.org/) (1.80+)

### Running Locally
```bash
npm install
npm run tauri dev
```

### Verification & Quality Gate
```bash
npm test                 # cargo check + cargo test + svelte-check
```
